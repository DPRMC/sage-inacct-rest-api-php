# Make zero unmapped endpoints the v1 gate

Status: accepted. For the current `1.0.0` plan, every public endpoint in the pinned `2026 R3` source must appear in the normalized inventory, have generated code and contract tests, and be verified against the Sage sandbox, with zero unmapped or silently skipped endpoints. This is a current release rule and may be revisited if later evidence changes the scope or validation model.
