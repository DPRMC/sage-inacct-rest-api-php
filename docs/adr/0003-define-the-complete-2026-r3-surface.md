# Define the complete 2026 R3 surface

Status: accepted. “Complete” means every publicly documented REST endpoint in Sage Intacct `2026 R3`, including authentication, object CRUD, workflows, service endpoints, asynchronous jobs, reports, file downloads, exports, and delivery queues. Permission-gated endpoints remain in the surface with documented prerequisites; deprecated endpoints are excluded unless present in the release definition. Webhook receiving is tracked separately as an integration capability because it is not a Sage REST endpoint.
